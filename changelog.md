# AFWC changelog

## v1.0.0
- First release with two features.
- **High-accuracy frame analysis**: the scanner re-plays the level from snapshots and moves each click earlier and later,
  tick by tick, until the attempt fails. The result is checked against how the real attempt ended; a mismatch is flagged.
- **Frame window counter**: every click of the active run gets a colour-coded ring with its frame window, label
  counters in the corner and an info line.
- Records every attempt and saves completed runs per level.
- **AFWC menu**: actions, quick switches for display / recording and the scanner options in one popup; opened from the pause menu, the main menu or the O key.
